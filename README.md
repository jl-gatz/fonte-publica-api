# Fonte Pública API

Infraestrutura pública para dados jornalísticos estruturados,
com foco em:

- Proveniência verificável
- Histórico de correções
- Governança editorial
- Acesso aberto e ético

Esta API não entrega “verdades finais”, mas **registros auditáveis**.
